# Revorfest

Official club app for **Revorfest** — EA Sports FC Pro Clubs (PS5 & PC cross-play).

Next.js (App Router) · Tailwind CSS v4 · Motion · Neon Postgres · Vercel Blob · deployed on Vercel.

## Roadmap
1. **Phase 1 — Look & feel:** design system, responsive shell, club overview dashboard (placeholder data), kit showcase, PWA.
2. **Phase 2 — Players:** invite-code signup, unique jersey numbers, avatar + PIN login, roster & profiles, admin panel.
3. **Phase 3 — EA stats:** scheduled EA Pro Clubs sync, leaderboards, match archive, Player / Worst Player of the Week.
4. **Phase 4 — Matchday & Showdown:** attendance, tactical board, kit selector, Goal / Nyunda of the Week voting.
